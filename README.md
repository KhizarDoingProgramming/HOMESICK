## 💅 What's the vibe?
We ditched the boring corporate layouts and went full premium. This is a Next.js 14 App Router project built with Tailwind CSS and Framer Motion for those buttery smooth micro-animations. It's giving high-end agency mixed with Gen Z flavor.

### 🧠 Tech Stack
- **Framework:** Next.js 14 (App Router) ⚡️
- **Styling:** Tailwind CSS 🎨
- **Animations:** Framer Motion 🎬
- **Icons:** Lucide React 🔍
- **Language:** TypeScript 💙

## 🛠 Getting Started

Wanna spin this up locally? Say less.

```bash
# 1. Clone the repo
git clone git@github.com:KhizarDoingProgramming/HOMESICK.git

# 2. Install the vibes (dependencies)
npm install

# 3. Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
