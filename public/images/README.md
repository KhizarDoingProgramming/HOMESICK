# HOMESICK — Image Guide (for StudioLoop-level quality)

Your site looks "flat" because StudioLoop uses REAL photography.
CSS placeholders can't compete with actual images.

## Save these images in the folders below, then run `npm run dev`.

---

## 🖼️ HERO (`public/images/hero/`)

Save 6 images. These scatter across the full viewport like StudioLoop's chair/poster/t-shirt.

| File | What to save | Where to find |
|------|-------------|---------------|
| `1.webp` | A product or object photo (lamp, chair, book, device) | Unsplash, your own photos |
| `2.webp` | A design mockup or poster | Dribbble, Behance |
| `3.webp` | A tech device (phone, laptop, tablet) | Your own screenshots |
| `4.webp` | An abstract shape or graphic | Create in Figma |
| `5.webp` | A brand collateral (business card, packaging) | Unsplash "branding mockup" |
| `6.webp` | A lifestyle/workspace photo | Unsplash "workspace" |

**Format:** WebP or PNG (transparent BG = best)
**Size:** 400-600px wide
